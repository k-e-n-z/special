PROJECT PRIVATE
1) Keep index.html and the assets folder together.
2) Open index.html locally to preview (internet is needed for map tiles, Leaflet, and Google Fonts).
3) For GitHub Pages: upload index.html and the assets folder to the repository root.
4) In GitHub: Settings -> Pages -> Deploy from a branch -> choose main and /(root).
5) Password gate is a front-end gate only. The password can be found by someone inspecting the source; it is suitable for a personal surprise, not sensitive data.
6) Concert audio: choose a file in the concert section during the visit. For a persistent song, place an audio file in assets and update the audio element source in index.html. Use audio you have permission to share.
